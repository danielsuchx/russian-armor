# Changelog

Изменения Russian Armour. Формат — Keep a Changelog.

## [Unreleased]

### Added

- **Отслеживание ошибок восстановления watchdog в журнале событий.** Добавлены типизированные ошибки `WatchdogError` для сбоев запуска помощника и очистки маркера файла. Попытки запуска и выхода теперь ловят исключения и логируют их в историю приложения с типом `.warning`. При системном выходе гарантируется чистое завершение; жёсткое завершение запускает помощника для паузы Claude.

### Улучшения

- **Определение системного профиля Happ — подготовка к VPN kill switch.** `HappVPNDiscovery` сопоставляет подключённый системный профиль с его интерфейсом и основным IPv4-сервисом, вместо предположения, что любой `utun` является VPN. Несколько активных профилей и некорректный интерфейс отклоняются. Проверено на подключённом Happ и тестовых состояниях; это только read-only заготовка, она не подключена к UI, не устанавливает PF и не подтверждает блокировку или IPv6.

- **Предварительный аудит конфигурации Keenetic/Xkeen.** Добавлен офлайн-скрипт `scripts/audit-xkeen-snapshot.py`, который ищет в локальном снимке прямые выходы, балансировщики и цепочки маршрутизации, не выводя секреты и не изменяя роутер. Отсутствие замечаний намеренно не считается доказательством kill switch: правила Keenetic, IPv6 и поведение при сбое требуют проверки на самом роутере. Добавлены тесты размера файлов, symlink-защиты, дубликатов JSON и отсутствия утечки чувствительных значений.


- **Усиление process-level защиты.** Добавлены routing socket macOS с отсечением дублирующихся событий, распознавание npm Claude Code по аргументам `node`/`bun`/`deno`, отдельный watchdog с паузой Claude и перезапуском после crash, а также обязательное согласие ipwho.is и IPinfo по внешнему IP. Страну определяет основной сервис ipwho.is: GeoIP-базы могут расходиться даже для одного адреса, поэтому их оценка не участвует в консенсусе. Плановая проверка не замораживает подтверждённую сессию; расхождение IP и системная смена маршрута по-прежнему закрывают доступ.

- **Системный per-app канал Claude, до интеграционной проверки.** Добавлен `ArmourProxyExtension`: TCP через password-authenticated SOCKS5 поверх pinned TLS, DNS-over-TCP вместо UDP53, блокировка другого UDP и отсутствие direct fallback. Контроллер устанавливает расширение, настраивает подписи Anthropic Desktop/native Code и дочерние процессы, хранит пароль в Keychain и проверяет heartbeat текущей конфигурации. UI поддерживает импорт подключения. Добавлены отдельная подписанная сборка и проверка Apple profiles; ad-hoc сборка расширение не активирует. Первый адаптер — подготовка защищённого входа Xkeen без изменения живого роутера. Проект рассчитан на разных пользователей, сборку подписывает сопровождающий. Без profiles ещё не подтверждены установка без MDM, Keychain, старые сокеты и поведение при crash/reboot. Готовность к массовому выпуску не заявляется; см. `docs/protection.md`.

- **Локальный индекс сетевых соединений по явному включению.** Раньше приложение видело только состояние сети, интерфейсы и наличие Claude Desktop; добавлены снимки TCP и UDP с заданным peer, таблица процессов/PID, адресов, портов, протоколов и состояний с поиском и IPv6/loopback-фильтрами. Выбраны публичные read-only `libproc` API: для этого этапа не нужны перехват пакетов, TLS-прокси, root/helper или Network Extension. Неполнота опроса и ограничения доступа видны, отсутствие записей не считается защитой. Код: `Traffic.swift`, `SocketTrafficReader.swift`, `TrafficMonitor.swift`, `TrafficView.swift`; интеграция в `AppModel.swift`, `NativeStatusMenu.swift`, `RussianArmourApp.swift`. Сбор ограничен текущим UID, повышенные права отвергаются; PID/start time и поколение сокета различают повторное использование идентификаторов. Адреса и включение не сохраняются, stop/сон очищают снимок, поздние ответы отменённых поколений отбрасываются. Добавлены fixture-тесты адресов/портов/прав, переходов, приватности и действия меню; 18 тестов моделей/monitor/reader выполнены без ошибок. Живое окно и полный снимок соединений ещё не проверены end-to-end.

- **Диагностика внешнего выхода без привязки к VPN-приложению.** Добавлен выбор расположения VPN, включая роутер. Отвергнута проверка «есть utun — значит VPN работает»: системные службы тоже создают туннели, а VPN на роутере не обязан создавать их на Mac. По явному подтверждению выполняется запрос к Country.is; адрес и страна не сохраняются в историю и не считаются проверкой маршрута Claude. Код: `EgressChecker.swift`, `LocalDiagnosticsReader.swift`, модели `Diagnostics.swift` и `EgressObservation.swift`.
- **Ограниченный срок применимости результата.** Внешняя проверка сбрасывается при наблюдаемых изменениях сети, смене режима VPN, сне и истечении срока. Поздний ответ отменённой проверки отбрасывается. Автоматических внешних повторов нет; добавлены тесты переходов и миграции настроек.

### Changed

- **Кнопка запуска Claude под перепроверкой.** По запросу пользователя в панели добавлена строка «Запустить Claude безопасно» сразу под «Перепроверить», с общим стилем строк. Пока безопасный запуск не реализован, действие отключено и пояснено подсказкой; проверка недоступности на границе контроллера сохранена. Обычный запуск не маскируется под защищённый.

- **Пояснение контроля страны в две строки.** Текст сокращён с проверкой реального переноса при ширине 312 pt и системном шрифте 12 pt; добавлен регрессионный тест раскладки. Предыдущая оценка по числу предложений оставляла три строки. Условия паузы и риск отправки данных до неё сохранены, шрифт не уменьшен, обрезка текста не используется. Логика защиты не изменена.

- **Короткое пояснение вместо инструкции по настройке роутера.** В окне «О защите Claude…» оставлены два пункта: автоматическая проверка IP/страны и отсутствие блокировки Claude в текущей версии. Убраны три шага с VPN, Kill Switch и ручной перепроверкой. Добавлена кнопка «Понятно», настройки доступны только при отключённой автопроверке, размер окна соответствует тексту. В основной панели упрощены пояснения и убраны предложения отдельно настраивать защиту. `swift test`: 100 тестов, 4 GUI-теста пропущены, ошибок нет. Приложение пересобрано и перезапущено; в живом интерфейсе проверены полный текст без прокрутки и закрытие кнопкой «Понятно».

- **Понятный путь к защите.** Вместо вводящего в заблуждение «Защита не настроена» показано «Защита недоступна» с пояснением и заметной кнопкой «Как защитить соединение…». Инструкция учитывает VPN на Mac/роутере, объясняет подключение, Kill Switch и проверку IP и открывает настройки диагностики. Неработающие действия запуска/закрытия Claude и паузы убраны из основной панели. Сетевая блокировка в приложение не добавлена.

- **Панель по предоставленному визуальному референсу.** Вместо основного текстового `NSMenu` левый клик по щиту открывает панель 340 × 532 pt с двумя колонками, четырьмя последними событиями, часами и группировкой действий как на изображении пользователя. Возврат к панели обусловлен новым явным требованием воспроизвести эту композицию: стандартный `NSMenu` не задаёт такую сетку. Прежнее системное меню сохранено по правому клику, чтобы не потерять сетевые соединения, ручную проверку IP и пояснения. Стекло остаётся системным `NSVisualEffectView`: дополнительное затемнение отвергнуто пользователем, добавленный тонирующий слой удалён. Реальные данные и автоматическое определение IP сохранены; «Защищено», закреплённая страна, имя VPN и число сессий Code не выдумываются, отсутствующие механизмы безопасного запуска/закрытия и паузы не имитируются кликабельными действиями. Код: `StatusPanelView.swift`, `StatusPanelController.swift`, `NativeStatusMenu.swift`; проверки: `StatusPanelTests.swift`. Девять новых тестов, включая настоящее окно, рендер, Escape и закрытие перед переходом в настройки; полный прогон с GUI-проверками панели — 96 тестов прошли, 1 отдельный GUI-тест системного меню пропущен. Сборка и ad-hoc подпись проверены; в запущенной `.app` проверены открытие через щит и автоматический результат ipwho.is. Визуальная геометрия проверена, попиксельное совпадение системного материала с референсом не заявляется.

- **Автоматическое определение IP и страны вместо обязательной кнопки.** Пользователю нужен актуальный IP без повторного выбора сервиса; после подтверждённой пользователем работы альтернативного сервиса выбран ipwho.is по умолчанию. Прежняя политика «каждый запрос только после отдельного подтверждения» заменена включённой по умолчанию автопроверкой при доступной сети, после сетевых изменений/wake и примерно раз в минуту; старые настройки VPN и журнала сохраняются. В настройках добавлены сохраняемый opt-out и выбор поставщика; выключение и смена сервиса отменяют запрос и очищают результат. Ручное обновление не требует диалога при включённой автоматике, при выключенной остаётся разовый запрос с выбором сервиса. Сон/offline приостанавливают запросы, секундная задержка объединяет быстрые сетевые события, повторы не идут параллельно; поздние ответы отменённого поколения отбрасываются. Автоматический fallback и отключение проверки сертификатов по-прежнему отвергнуты: повтор идёт только к выбранному сервису. Автоматические результаты не пишутся в журнал, чтобы минутный опрос не вытеснял историю событий; IP/страна не сохраняются. Код: `AppModel.swift`, `Models.swift`, `EgressObservation.swift`, `NativeStatusMenu.swift`, `SettingsView.swift`, `ReadinessView.swift`; проверки: `AutomaticEgressTests.swift`, миграция настроек и меню. Полный `swift test`: 87 тестов прошли, 1 графический тест пропущен, ошибок нет; `.app` пересобрана и проверена ad-hoc подписью. Живой автоматический запрос из новой сборки ещё не проверен. TLS-сбой Country.is не объявляется исправленным.

- **Системное меню вместо кастомной карточки.** Промежуточная тёмная SwiftUI-панель 360 × 562 pt отвергнута после визуальной проверки пользователем: нужна нативная macOS Design System, а не её имитация. Меню перенесено на AppKit `NSStatusItem` + `NSMenu`, без кастомных представлений строк, фона, принудительной темы, hover-эффектов и фиксированной высоты. Заголовок уменьшен до 13 pt, щит — до 12 pt; часы справа убраны. Код: `NativeStatusMenu.swift`; бывший `MenuPanel.swift` удалён. Окна настроек, истории и пояснений остаются на SwiftUI. `NativeMenuTests.swift` проверяет системные строки и действие истории вместо прежнего теста размера карточки.
- **Атомарное обновление development bundle.** Скрипт сборки заменяет бинарный файл через промежуточный файл и переименование, а не обрезает исполняемый файл работающего процесса. Обновлённую версию нужно открыть после завершения старого процесса.

### Fixed

- **Заголовок неактивной защиты.** По запросу пользователя состояние паузы теперь называется «Защита неактивна» вместо «Claude на паузе» во всех поверхностях, использующих `ProtectionState.title`. Причина, количество приостановленных процессов и политика разрешённой страны не изменены. Добавлена проверка заголовка и сохранения причины.

- **Активный контроль страны больше не выглядит отключённой защитой.** В `ProtectionState` состояние подтверждённой страны получило название «Контроль страны включён» и отдельный полузаполненный щит; панель и окно пояснений показывают его зелёным. Раньше все состояния, кроме системного канала, отображались перечёркнутым щитом и оранжевым цветом. Полный щит и разрешение безопасного запуска не назначаются проверке IP: маршрут Claude не подтверждён, ограничение явно сохранено в пояснении. Управление процессами и watchdog не изменены. Добавлены регрессионные проверки положительной индикации и предупреждений.

- **Устранён смещённый кадр при раскрытии диагностики.** Проверка только конечной геометрии пропустила мерцание: SwiftUI успевал показать новую компоновку внутри старых границ до отложенного изменения окна. Измерение через `GeometryReader`/preference и следующий проход main queue заменены callback из `NSHostingView.layout()`: окно и документ получают согласованные размеры до возврата из компоновки. Независимая анимация SwiftUI отключена, обновление видимого окна синхронизировано до flush; одной перестановки `setFrame` было недостаточно — первая видеопроверка всё ещё показывала дефект. Код: `StatusPanelController.swift`, `StatusPanelView.swift`. Новый GUI-тест в `StatusPanelTests.swift` проверяет размер без ожидания следующего прохода run loop. В пересобранной запущенной `.app` записаны повторные клики; на покадровой проверке раскрытия и сворачивания прежнего смещённого кадра не обнаружено, верхняя граница остаётся на месте. Полный прогон с GUI-тестами панели: 156 тестов, 1 пропущен, ошибок нет.

- **Диагностика раскрывает панель вниз, сохраняя верхнюю границу.** Верхний край окна остаётся под значком в строке меню, при сворачивании возвращается прежняя высота. Раньше постоянно подключённый `NSScrollView` позволял `DisclosureGroup` прокручивать содержимое до изменения размера окна; принудительное возвращение прокрутки наверх не устраняло переходный сбой. Теперь обычная панель размещает SwiftUI напрямую, прокрутка подключается только при нехватке высоты экрана, а состояние раскрытия явно запускает перерасчёт размера. Код: `StatusPanelController.swift`, `StatusPanelView.swift`; регрессионный GUI-тест в `StatusPanelTests.swift` проверяет три цикла раскрытия/сворачивания, неизменность верхнего края и отсутствие прокрутки. На этом этапе полный прогон с GUI-тестами панели: 155 тестов, 1 пропущен, ошибок нет; в живой `.app` проверены конечные размеры 506 и 612 pt. Снимок и тест конечной геометрии не обнаружили переходное мерцание, о котором пользователь сообщил позже; оно исправлено отдельным изменением выше.

- **Более честный статус проверки страны и обработка сбоев.** Совпадение GeoIP больше не объявляется проверенным системным каналом: маршрут отдельных процессов не подтверждается, а опрос не исключает передачу до остановки. Для пользовательского выбора и правила всегда показывается результат ipwho.is после согласования IP, даже если первым выбран IPinfo. Невозобновлённые процессы сохраняются для повтора, список PID расширяется при переполнении, а отдельные изменения маршрутов не отбрасываются из-за неизменного глобального отпечатка. Код: `AppModel.swift`, `ProcessProtectionController.swift`, `RouteChangeObserver.swift`, `Models.swift`. Это не заменяет сетевой kill switch и не устраняет задержку обнаружения.

- **Панель без пустого низа и без ложной активации.** После жалобы на отступ убраны фиксированные 550 pt и пустые строки отсутствующих событий: `StatusPanelView.swift` измеряет содержимое, `StatusPanelController.swift` подстраивает окно, сохраняя привязку к щиту, а на коротком экране оставляет прокрутку до настроек и выхода. В панели видны ожидание сети, запрос, автоматическое обновление IP, ошибка и сохранённый opt-out; VPN/IPv6/состояние Claude и подробности защиты сохранены в раскрываемой диагностике, а IP и страна остаются на первом уровне. `ReadinessView.swift` больше не требует ручной перепроверки для начала автоматической диагностики и отличает её от отсутствующей блокировки Claude. Обещание «всё защищено» по одному IP отвергнуто: выбран охват только Claude Desktop/Code, но системного механизма блокировки в проекте пока нет. Добавлены проверки геометрии, feedback/opt-out и opt-in GUI-сценарии изменения высоты/прокрутки в `StatusPanelTests.swift`. Для этого изменения выполнен только просмотр исходников и проверка diff; сборка, тесты и живой интерфейс не запускались из-за неподтверждённой полной изоляции, требуемой security-audit.

- **Диагностика сбоя проверки IP и явный выбор альтернативного сервиса.** В существующем системном журнале Russian Armour найден обрыв TLS до ответа Country.is: `NSURLErrorDomain −1200`, underlying `−9816` (закрытие сессии без уведомления); что именно закрыло соединение на стороне сервиса/сетевого пути, не установлено. Раньше приложение скрывало сетевую причину, а ошибка и сброшенный результат выглядели одинаково. Теперь меню различает эти состояния, системное окно показывает безопасную причину и код; локальные события не стирают последнюю ошибку. В подтверждении можно явно выбрать ipwho.is или Country.is; результат содержит поставщика, парсеры разделены, `success: false` не принимается за успех. Автоматический fallback отвергнут, чтобы не передавать IP второму сервису без отдельного согласия; отключение TLS/проверки сертификатов также отвергнуто. IP/страна и сырые ошибки не сохраняются. Код: `EgressObservation.swift`, `EgressChecker.swift`, `AppModel.swift`, `NativeStatusMenu.swift`; пояснения синхронизированы в окнах. Добавлены парсерные, state-machine, consent/menu и in-memory URLProtocol-тесты, включая отказ без fallback и поздний ответ отменённого поставщика. Исходники приложения и всех тестов проходят статическую проверку типов; полный `swift test`: 72 теста прошли, 1 GUI-тест меню пропущен, ошибок нет. Новая `.app` упакована и проверена ad-hoc подписью; запущенный экземпляр не перезапускался, живой запрос к альтернативному сервису не выполнялся — восстановление связи не заявляется.

- **Подпись собранного development bundle.** Проверка после копирования нового SPM executable обнаружила несогласованность standalone-подписи с ресурсами `.app`. Скрипт `scripts/build-app.sh` теперь после упаковки подписывает bundle локальной ad-hoc подписью и проверяет её строго. Developer ID и notarization не добавлены; для обновлённой сборки `codesign --verify --strict` выполнен успешно.

- **Фактическое отображение иконок на macOS 27.0.1.** Предыдущего назначения `NSMenuItem.image` оказалось недостаточно: минимальный открытый `NSMenu` не создавал изображения для исходных SF Symbols, хотя они были ненулевыми и отдельно рисовались. Тот же символ внутри drawing-backed template `NSImage` отображается. В `NativeStatusMenu.swift` изменена только подготовка изображений: системные строки, Retina-масштабирование и цвета disabled/highlight сохранены; кастомная панель не возвращается. `NativeMenuRenderingTests.swift` по явному включению открывает реальное меню, проверяет видимые `NSImageView` и непустые пиксели в светлой и тёмной темах — прежняя проверка `image != nil` этот сбой пропускала.

- **SF Symbols в нативном меню.** После перехода на `NSMenu` строки страны, VPN, IP, IPv6, Claude и защиты остались без значков; им назначены системные символы, существующие иконки заголовка и действий сохранены. Сон и пробуждение теперь записываются с отдельными типами событий и показываются луной и солнцем в меню и истории. Значки вписываются в общий размер без растяжения пропорций; маленький щит, заголовок без часов и нативные строки сохранены — возврат к кастомной панели не нужен. Код: `NativeStatusMenu.swift`, `Models.swift`, `AppModel.swift`; тесты проверяют изображения строк и действий, обновление событий и сохранение новых типов журнала.
