# 🏴‍☠️ Russian Armour

Russian Armour помогает проверять подключение к интернету на Mac. Приложение показывает внешний IP-адрес и примерную страну, а также сведения о сети и запущенном Claude Desktop. Его значок находится в строке меню вверху экрана.

> **Важно: приложение пока не защищает от утечек.** Оно не блокирует интернет при отключении VPN, не меняет сетевые настройки и не останавливает другие программы. Проверка показывает результат только для запроса самого Russian Armour. Она не доказывает, что Claude, браузер или другие приложения подключаются через VPN.

## Что умеет приложение

- Показывает внешний IP-адрес и страну, которую определил сервис проверки.
- Обновляет результат автоматически или по вашему запросу.
- Показывает информацию о локальной сети и обнаруженных сетевых интерфейсах.
- Позволяет посмотреть некоторые сетевые соединения приложений.
- Показывает, установлен ли и запущен ли Claude Desktop.
- Сохраняет настройки и историю событий на вашем Mac.

## Как запустить

Сейчас готового установщика нет. Чтобы собрать приложение из исходного кода, нужны macOS 13 или новее и Xcode с поддержкой Swift 5.9 или новее. Xcode можно установить из App Store. В настройках инструментов разработчика должна быть выбрана установленная версия Xcode.

1. Скачайте исходный код проекта с GitHub и откройте папку проекта в Терминале.
2. Выполните команды:

   ```bash
   bash scripts/build-app.sh
   open "dist/Russian Armour.app"
   ```

3. Найдите значок щита в строке меню вверху экрана и нажмите на него. Приложение не отображается в Dock.

Права администратора для сборки и запуска не нужны. Если вы пересобрали приложение, сначала закройте работающую версию через её меню, а затем откройте новую.

Сборка подписана локально, но не заверена Apple для распространения. На другом Mac система может предупредить о неизвестном разработчике или заблокировать запуск. Автоматического обновления и универсальной сборки для разных архитектур Mac пока нет.

## VPN на Mac или роутере

В настройках укажите, где работает VPN:

- **На роутере.** Приложению не требуется находить VPN-подключение на самом Mac.
- **На этом Mac.** Приложение покажет обнаруженные локальные сетевые интерфейсы, которые могут использоваться VPN. Их могут создавать и службы Apple, поэтому это не доказательство работы VPN.
- **Не указано.** Приложение не предполагает, где настроен VPN.

Это указание помогает отображать информацию. Приложение не подключается к роутеру и не меняет настройки VPN.

## Проверка IP-адреса и страны

IP-адрес помогает интернет-сервисам определить, откуда пришёл запрос. Страна определяется приблизительно и может отличаться у разных сервисов.

Автоматическая проверка включена по умолчанию. После подключения к сети приложение обращается к сервису **ipwho.is** и затем повторяет проверку примерно раз в минуту, а также после некоторых изменений сети и пробуждения Mac. В настройках можно выбрать **Country.is** или выключить автоматическую проверку.

В меню можно обновить результат вручную. Если автоматическая проверка выключена, разовая проверка предложит выбрать сервис и подтвердить запрос. При ошибке приложение покажет сообщение. Если автоматическая проверка включена, оно повторит запрос к тому же сервису примерно через минуту.

Выбранный сервис получает IP-адрес, с которого к нему обращается приложение. Russian Armour не записывает этот адрес и определённую страну в настройки или историю событий. Результат временно хранится в памяти приложения.

Даже если отображается ожидаемая страна, другие приложения могут использовать другое подключение. Сама проверка не подтверждает их защиту.

## Сетевые соединения

В меню щита выберите **«Сетевые соединения…»**, а затем **«Начать наблюдение»**. В окне появится список некоторых соединений процессов текущего пользователя. Открытие окна само по себе наблюдение не запускает.

Список может быть неполным: например, короткие соединения могут не попасть в него. Он не показывает содержимое сообщений и не подтверждает, что соединение проходит через VPN. Данные последнего снимка хранятся в памяти и очищаются при остановке наблюдения или переходе Mac в сон. После перезапуска приложения наблюдение выключено.

## История и конфиденциальность

История содержит последние события приложения и хранится локально. В неё не записываются IP-адреса, адреса посещаемых страниц, токены или содержимое запросов. Историю можно очистить в приложении.

## Для разработчиков

Для сборки версии с оптимизацией выполните:

```bash
bash scripts/build-app.sh release
```

Для запуска тестов:

```bash
swift test
```

Исходный код находится в `Sources`, тесты в `Tests`, а скрипт сборки в `scripts/build-app.sh`. Отдельный тест отображения системного меню требует графической сессии macOS:

```bash
RUSSIAN_ARMOUR_RENDER_MENU_TESTS=1 swift test --filter NativeMenuRenderingTests
```
