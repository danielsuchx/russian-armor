
# Russian Armour

Нативное приложение для строки меню macOS. Системное меню AppKit (`NSStatusItem` + `NSMenu`), окна на SwiftUI, SF Symbols, без сторонних зависимостей.

> **Версия 0.2.0 — диагностика подключения, не сетевой kill switch.**
> Приложение не изменяет файрвол и маршруты, не блокирует трафик и не управляет процессами Claude. Внешний IP и страна одного проверочного запроса не доказывают защиту других соединений.

## Требования и запуск

- macOS 13 или новее.
- Xcode с поддержкой Swift 5.9 или новее, выбранный через `xcode-select`.

```bash
bash scripts/build-app.sh
open "dist/Russian Armour.app"
```

После запуска нажмите перечёркнутый щит в строке меню. В Dock приложение не отображается. Настройки, история и пояснение о защите открываются отдельными окнами.

Сборка для текущей архитектуры Mac; для release используйте `bash scripts/build-app.sh release`. Это локальный development bundle с ad-hoc подписью и её проверкой после упаковки; Developer ID, notarization, универсальный дистрибутив и автообновления пока не настроены. Права администратора не требуются; запускать через `sudo` не нужно.

После пересборки завершите старый процесс через меню приложения и откройте `.app` заново. Скрипт заменяет исполняемый файл атомарно, не обрезая файл, который использует работающий процесс.

## VPN на роутере и на Mac

В настройках выберите «Где работает VPN»:

- **На роутере:** локальный VPN-клиент и интерфейс `utun` не требуются. Их отсутствие не считается ошибкой.
- **На этом Mac:** дополнительно показываются обнаруженные включённые интерфейсы `utun`. Их могут создавать и службы Apple; это не подтверждение VPN-маршрута.
- **Не указано:** приложение не пытается угадать способ подключения.

Это пользовательское указание, а не результат проверки. Приложение не подключается к роутеру, не получает его учётные данные и не меняет конфигурацию VPN.

## Внешний IP и страна

Автоматическая проверка **включена по умолчанию**, в том числе при обновлении старых настроек. Сервис по умолчанию — **ipwho.is** (`https://ipwho.is/?fields=success,ip,country_code`). После запуска приложение дожидается доступной сети и отправляет запрос без кнопки и диалога. Проверка повторяется после изменения сети/туннелей, смены режима VPN и пробуждения, а также примерно раз в минуту. Быстрые изменения сети объединяются задержкой в одну секунду; параллельные запросы не запускаются.

В настройках можно отключить **«Определять IP и страну автоматически»** или выбрать **Country.is** (`https://api.country.is/`). Выключение отменяет текущий запрос и очищает результат; выбор сервиса и выключенное состояние сохраняются между запусками. Сервис получает внешний IP запроса и возвращает адрес и оценку страны. При ошибке автоматический режим повторяет запрос к **тому же сервису** примерно через минуту: переключения на другого поставщика без выбора пользователя нет. Во сне и при отсутствии доступной сети автоматических запросов нет.

Кнопка **«Обновить IP и страну»** позволяет немедленно запросить выбранный в настройках сервис без дополнительного диалога. Если автопроверка выключена, **«Проверить IP и страну…»** по-прежнему предлагает разовый выбор сервиса и подтверждение передачи IP; отмена не выполняет запрос и автопроверка не включается.

- Результат относится только к запросу **Russian Armour**, а не к Claude Desktop, Claude Code, браузеру или всем соединениям Mac. На результат могут влиять прокси и раздельная маршрутизация.
- Страна — оценка поставщика геоданных, другие сервисы могут определять её иначе.
- IP и страна не записываются в `UserDefaults` или журнал, остаются в памяти до сброса. Периодические автоматические результаты не заполняют историю одинаковыми событиями.
- Результат сбрасывается при обнаруженном изменении сети/туннелей, ручной перепроверке, смене режима VPN, смене сервиса, выключении автопроверки и сне. Через минуту он считается устаревшим; при включённом автоматическом режиме запускается новая проверка. Изменение VPN на роутере может не породить событие на Mac, поэтому остаётся периодическое обновление.
- Сессия эфемерная, без постоянных cookies и кэша. Автоматические перенаправления запрещены, ответ ограничен 4 КиБ, заданы таймауты.
- Недоступность сервиса или непонятный ответ не подменяются успешным результатом. `success: false` у ipwho.is считается отказом, даже при HTTP 200. Поздний ответ отменённого запроса не возвращает устаревший IP.
- Меню различает ожидание сети, выполняемый запрос, результат, выключенную автопроверку и ошибку. Строка **«Проверка IP не удалась — подробнее…»** открывает системное окно с безопасной причиной и объяснением автоматического повтора либо ручного выбора сервиса.
- Проверка сертификатов не отключается. Из ошибок macOS используются только известный домен и числовой код; исходные `NSError.userInfo`, URL, сведения о прокси и текст ответа сервиса не сохраняются и не показываются.

Доступность провайдера и точность его данных не гарантируются. Контракт альтернативного сервиса: [официальная документация ipwho.is](https://ipwhois.io/documentation). В тестах используются вымышленные ответы и документационные IP-адреса; `EgressCheckerTests` перехватывает все запросы через `URLProtocol` в памяти, без внешнего или локального сервера. `AutomaticEgressTests` проверяет запуск от сетевого события, периодическое обновление и повтор после сбоя, opt-out, сон/wake, смену поставщика, отмену и отбрасывание поздних ответов с управляемым временем.

**Граница проверки:** ранее по системным событиям подтверждён обрыв TLS до ответа Country.is (`NSURLErrorDomain −1200`, underlying `−9816`). Его причина не установлена и этим изменением не исправляется; поэтому по умолчанию используется ipwho.is. Полный `swift test`: 87 тестов прошли, 1 графический тест явно пропущен, ошибок нет. Новая `.app` собрана и прошла проверку локальной ad-hoc подписи. Автоматический цикл проверен тестами без внешних запросов; живой автоматический запрос из обновлённой `.app` ещё не проверен.

## Индекс сетевых соединений

Из меню щита откройте **«Сетевые соединения…»**. Само открытие окна не запускает сбор; кнопка **«Начать наблюдение»** явно включает его до остановки или завершения приложения.

- Нативная таблица: имя процесса и PID, TCP/UDP, IPv4/IPv6, локальный и удалённый IP/порт, состояние TCP. Есть поиск, фильтр IPv6 и скрытие loopback.
- Используются публичные `proc_listpids`, `proc_pidinfo`, `proc_pidfdinfo`. Только процессы текущего пользователя, без root, командных строк/окружения процессов и чтения сокетов. Повышенный effective UID отвергается.
- Между снимками — пауза 5 секунд; локальный сбор выполняется вне main thread. Ограничены число процессов, дескрипторов, записей и длительность сканирования; достижение лимита и недоступные объекты отмечаются как неполнота.
- Это **не журнал пакетов и не измеритель объёма трафика**. Слушающие сокеты и UDP без закреплённого адресата не включаются, короткие соединения могут быть пропущены. Имя процесса не доказывает подпись приложения; `node` не считается автоматически Claude Code.
- Нет DNS/GeoIP-запросов по назначениям, расшифровки TLS, чтения HTTP, содержимого запросов, токенов или cookie.
- Последний снимок хранится только в оперативной памяти. Ни IP/порты, ни включение сбора не сохраняются в историю/`UserDefaults`. Stop и сон очищают данные; после wake сбор возобновляется только если ранее был включён, после перезапуска выключен.
- Наблюдаемая смена сети, туннелей, режима VPN и ручная перепроверка сбрасывают снимок. Ответ старого поколения не может вернуть старые адреса.
- Адрес назначения сокета **не подтверждает маршрут VPN**: приложение не знает, куда роутер направил пакет или что сделал локальный прокси. IPv6-соединение само по себе не является утечкой. Статус защиты остаётся «не настроена».

**Статус проверки этой новой функции:** выполнены статическая проверка типов и 18 тестов моделей, monitor/lifecycle/приватности и декодирования сокетов, включая чтение собственного незакреплённого UDP fixture через `libproc`. Полный пакет: 87 тестов прошли, 1 GUI-тест меню пропущен, ошибок нет. Обновлённая `.app` упакована. Новое окно и полный сбор снимка живых соединений не проверены end-to-end; unit-тесты не доказывают полноту наблюдения реального трафика.

## Локальная диагностика и интерфейс

- Настоящее системное меню `NSMenu`, без кастомных строк-представлений, фона, принудительной темы, скруглений и фиксированной высоты. Размеры и навигация соответствуют настройкам macOS.
- Компактный заголовок 13 pt и SF Symbol щита 12 pt, без часов справа. Строки страны, VPN, IP, IPv6, Claude и защиты; время событий доступно в подсказках. Статус «Защита не настроена» остаётся до реализации блокировки.
- `NWPathMonitor` наблюдает локальную доступность сети; это не проверка доступа в интернет.
- `getifaddrs` читает имена и флаг `IFF_UP` у интерфейсов, не их IP-адреса.
- Claude Desktop обнаруживается по bundle identifier, без чтения команд терминала и без подсчёта сессий Code. Это обнаружение приложения, не проверенная идентичность для правил безопасности.
- Локальная диагностика обновляется при сетевых событиях, запуске/завершении приложений и раз в 10 секунд. Во сне опрос приостанавливается; поздние ответы отбрасываются.
- История содержит последние 100 событий. Очистка требует подтверждения.
- «Что нужно для защиты?» объясняет, что уже доступно и каких механизмов ещё нет; кнопок фиктивной активации нет.

Настройки и история хранятся локально в домене `app.russian-armour.desktop`. Журнал не содержит IP, URL трафика, имён интерфейсов, токенов или содержимого запросов. Отключение записи изменений сети не удаляет прошлую историю и не отключает события жизненного цикла приложения.

## Разработка и проверки

```bash
swift test
```

Для разработки откройте `Package.swift` в Xcode. Для обычного запуска используйте `.app`: он содержит `Info.plist` с `LSUIElement`.

Тесты `NativeMenuTests` проверяют отсутствие кастомных представлений в строках меню, размер заголовка и щита, отсутствие часов в заголовке, сочетания клавиш и вызов действия истории.

На macOS 27.0.1 напрямую назначенные SF Symbols не появились в нативном меню. Поэтому символы обёрнуты в drawing-backed template `NSImage`: строки остаются системными, и macOS по-прежнему выбирает их цвета. Отдельная интеграционная проверка открывает настоящее меню в обеих темах, проверяет видимые изображения и их пиксели, сохраняет только представление тестового меню в `.build/native-menu-{light,dark}.png`:

```bash
RUSSIAN_ARMOUR_RENDER_MENU_TESTS=1 swift test --filter NativeMenuRenderingTests
```

Для неё нужна доступная графическая сессия macOS; без переменной тест явно пропускается. Внешние запросы не выполняются, состояние и история пользовательского приложения не используются.

Структура:

```text
Sources/ArmourCore/          Модели, настройки, журнал, валидация ответа IP
Sources/RussianArmour/      Панель, окна, локальные наблюдатели и проверка выхода
Tests/ArmourCoreTests/      Проверки моделей, миграции настроек и ответов сервиса
Tests/RussianArmourTests/   Переходы состояний, приватность, сон, системное меню
Support/Info.plist         Метаданные приложения
scripts/build-app.sh       Сборка development .app
```

Следующий этап — прототип системного механизма блокировки и проверка поведения при отключении VPN, включая VPN на роутере. До этого интерфейс не обещает защиту от утечек.
