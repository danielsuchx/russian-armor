## Зачем это нужно

VPN может отключиться после сна Mac или при смене Wi-Fi. Russian Armor следит за изменениями подключения и приостанавливает распознанные процессы Claude, пока разрешённая страна выхода не подтверждена заново.

Приложение работает в строке меню вверху экрана. Оно контролирует **Claude Desktop, Claude Code и их найденные дочерние процессы**. Остальные программы не ставятся на паузу.

> **Важно**
>
> **По умолчанию это защита на уровне программ, а не сетевой фильтр.** Между изменением сети и паузой остаётся время, за которое данные могут уйти. Добавлен отдельный **экспериментальный** helper `ArmorFirewall`: root-служба + pf для всего Mac. Он не устанавливается и не включается автоматически; до рабочего использования обязательна проверка в macOS VM. Условия, исключения, установка и восстановление — в [документации kill switch](docs/kill-switch.md).

## Как работает защита

1. **При запуске Claude приостанавливается.** До проверки подключения и выбора разрешённой страны работа не продолжается.
2. **Проверяются IP и страна выхода.** При VPN на Mac запросы ipwho.is и IPinfo или резервного GeoJS привязаны к туннелю с подтверждённым подписанным владельцем. Каждый сервис сам определяет IP своего запроса; адреса должны совпасть. В режиме VPN на роутере используется обычный сетевой стек Mac — маршрут за роутером не виден.
3. **Вы задаёте разрешения при включённом VPN.** В разделе «Защита» можно разрешить текущую страну либо открыть «Правила допуска → Изменить правила…»: несколько стран, IP/CIDR, запреты и отдельные правила Desktop/Code. Запрет важнее разрешения; страна и дополнительные IP-ограничения должны совпасть.
4. **Дополнительно читаются сокеты самого Claude** и текущие маршруты macOS к их удалённым узлам. В режиме «VPN на этом Mac» обнаруженный внешний источник или маршрут вне туннеля вызывает паузу, даже если проверочные сервисы видят разрешённую страну.
5. **Claude продолжает работу**, пока подтверждение страны и снимок маршрутов свежие и не выявлено противоречий выбранному режиму VPN.
6. **Смена сети, запрещённый выход, ошибка или устаревшая проверка снова ставят Claude на паузу.** Для возобновления нужны три успешные проверки одного выхода с интервалом не менее двух секунд. Пропажа подтверждённого владельца локального туннеля не переключает проверку на Wi-Fi.

Проверки продолжаются в фоне. Неполученный ответ не считается успехом, а старая проверка не даёт бессрочного разрешения на работу.

Сокеты не раскрывают внешний IP после прокси или роутера. Локальные узлы отмечаются как непроверенный дальнейший выход; для VPN на роутере обычный интерфейс Mac не является признаком обхода VPN. Проверка страны по-прежнему относится к запросам Russian Armor, а не к запросам Claude.

> **Примечание**
>
> Во время паузы окно Claude может перестать отвечать. Это ожидаемо: процесс приостановлен, а не закрыт. Не нужно принудительно завершать его только из-за такой паузы.

- Подтверждение маршрута запросом к серверу самого Claude. Разные программы могут использовать разные прокси и маршруты.
- Строгий запрет сетевых пакетов до того, как приложение успело отреагировать.

Подробные условия и ограничения описаны в [документе о защите](docs/protection.md).

## Первый запуск

1. **Включите свой VPN.** Russian Armor не создаёт VPN-подключение за вас.
2. Нажмите на щит и откройте **«Настройки… → Защита»**. В поле **«Где работает VPN»** укажите роутер или этот Mac. Для VPN на Mac выберите владельца локального туннеля через **«Найти владельцев туннелей»**.
3. В блоке **«Правила допуска»** нажмите **«Проверить IP и страну»**, если проверка ещё не началась автоматически. Этот же выбор доступен в окне первоначальной настройки.
4. Убедитесь, что определилась нужная страна, затем нажмите **«Разрешить страну …»**.
5. После свежего подтверждения Claude продолжит работу. При сбое проверки в этом же окне появятся пояснение и возможность повторить запрос.

Если находитесь дома без VPN, не разрешайте домашнюю страну по привычке: приложение будет считать именно её допустимой.

Если VPN работает на роутере, приложение не обязано находить VPN-подключение на самом Mac. Это нормально. Russian Armor не запрашивает пароль от роутера и не меняет его настройки.

Левый и правый клик по щиту открывают одну и ту же панель состояния. Повторный клик закрывает её. Отдельного системного меню по правому клику нет.

### Правила допуска и самотест

Откройте «Настройки» → «Защита» → «Правила допуска» → «Изменить правила…».
Изменения остаются черновиком до «Сохранить и перепроверить». Сохранение отзывает
старый допуск и запускает новую серию проверок. Текущая разрешённая страна
переносится в общий профиль без добавления новых стран. В гибких правилах
учитываются обе геобазы: если они расходятся, обе страны должны быть разрешены;
запрет хотя бы одной не обходится разрешённым IP.

Профили выбираются вручную: «Дом» и «Работа» — названия, а не автоматическое
распознавание доверенной сети. Страновые и IP-правила проверяют публичный IP
проверочного запроса, не IP серверов назначения. Вводимые IP/CIDR сохраняются
локально в настройках; наблюдаемые адреса в историю не записываются.

При VPN на Mac блок «Владелец локального туннеля» показывает результат проверки
подписи владельца utun. Если туннелей несколько, выберите владельца. Если macOS
не даёт прочитать системный или root-процесс VPN либо нет IPv4, допуск не откроется:
такой VPN пока не поддерживается этим способом. Не меняйте режим на «роутер»,
если VPN фактически работает на Mac, ради обхода этой проверки.

В разделе «Диагностика» кнопка «Проверить паузу и продолжение» запускает одноразовый тестовый процесс:
его выполнение действительно останавливается и продолжается. Сессии Claude
не используются. Это проверка паузы, не гарантия блокировки сетевых пакетов.

### Соединения Claude

В настройках автоматически показывается отдельный снимок сокетов Claude Desktop, Claude Code и найденных потомков. После каждого чтения повторная проверка запускается примерно через секунду; снимок старше пяти секунд не разрешает работу. Неполное чтение или неизвестный маршрут внешнего узла вызывает паузу. Во время сна и перепроверки старые адреса очищаются.

Если уже открытый сокет остался с адресом обычного интерфейса, одного нового маршрута через туннель недостаточно для продолжения работы. После включения VPN может потребоваться закрыть и заново открыть Claude, чтобы пересоздать такие соединения. Данные сокетов не сохраняются на диск и не отправляются сервисам проверки IP.

Локальный узел может быть прокси или служебным соединением: его дальнейший выход неизвестен и сам по себе не вызывает паузу. Имена туннелей не подтверждают их владельца или страну. Текущий маршрут ОС не доказывает фактическую пересылку пакетов, особенно при per-app VPN или прокси.

### Сетевые соединения всех программ

Встроенное окно сетевых соединений показывает некоторые соединения программ текущего пользователя при включённом наблюдении.

Само открытие окна наблюдение не запускает. Список может быть неполным и не доказывает прохождение соединений через VPN. Содержимое сообщений не читается. После остановки наблюдения или перехода Mac в сон текущий список очищается. После перезапуска наблюдение выключено.

При включённых наблюдении и записи сетевых событий два последовательных снимка
с несколькими внешними адресами подписанного туннеля Happ добавляют событие
«У Happ несколько внешних адресов». Повторяющиеся снимки не создают новые записи
об одном и том же состоянии. Сами адреса в историю не попадают. Это могут быть
VPN-серверы, DNS или служебные узлы; событие не подтверждает число VPN-серверов.

### Новые события

Синие точки и счётчик отмечают непрочитанные события в панели состояния и окне
истории. Отметки сохраняются после перезапуска; уже существующая история при
обновлении считается прочитанной. В окне истории кнопка «Прочитать всё» снимает
отметки, сохраняя записи. Открытие панели или истории само по себе их не снимает.

## Конфиденциальность

**Что передаётся в интернет**

Для проверки подключения Russian Armor обращается к [ipwho.is](https://ipwho.is/) и [IPinfo](https://ipinfo.io/). При лимите или временной недоступности IPinfo резервный [GeoJS](https://www.geojs.io/docs/v1/endpoints/country/) самостоятельно определяет IP своего запроса. Каждый сервис видит внешний адрес собственного запроса, адреса должны совпасть; IP первого ответа не подставляется во второй запрос. В режиме защиты проверки планируются каждые 5 секунд, срок допуска — до 15 секунд от начала проверки. После восстановления нужны три успеха с интервалом не менее двух секунд. Два подтверждения обязательны, пока работает контроль страны.

Ответ HTTP 429 включает паузу запросов к ограничившему сервису: по `Retry-After`,
а без него — от 15 минут с увеличением при повторных лимитах. Смена выбранного
сервиса или повторное нажатие проверки не обходят эту паузу. Это состояние
хранится в памяти до выхода из приложения; после перезапуска лимит будет
проверен заново. Старое подтверждение не продлевается из-за лимита: если два
свежих ответа получить нельзя, Claude остаётся на паузе.

В диагностике отдельно включаются запросы раз в 15 секунд к `claude.ai/cdn-cgi/trace`
и `api.anthropic.com/cdn-cgi/trace` — без аккаунта, cookies, ключей и чатов.
По умолчанию выключены: это недокументированные endpoints, их поддержка не
гарантируется. Ответ относится к запросу Russian Armor, не доказывает маршрут
Claude и не используется для допуска. При ошибке — пауза не менее пяти минут,
при 429 соблюдается `Retry-After`. Адреса DNS из конфигурации macOS читаются
локально, без внешнего DNS-теста. Подробности и ограничения — в
[описании защиты](docs/protection.md#дополнительная-диагностика-сервисы-и-dns).

**Что остаётся на вашем Mac**

- Настройки, код разрешённой страны и история последних событий.
- Внешний IP и определённая страна временно хранятся в памяти, но не записываются в историю.
- Для восстановления собственных пауз сохраняются идентификаторы процессов и время их запуска. Команды и IP в этот файл не записываются.
- Аргументы распознанных интерпретаторов локально просматриваются для обнаружения Claude Code, но не сохраняются и не отправляются сервисам.
- Данные наблюдения за соединениями хранятся в памяти. Содержимое сообщений, токены и адреса посещаемых страниц в историю не записываются.

## Вопросы и ответы

<details>
<summary><strong>Это VPN?</strong></summary>

Нет. Russian Armor приостанавливает распознанные процессы Claude, если разрешённый выход не подтверждён. VPN нужно настроить отдельно на Mac или роутере.

</details>

<details>
<summary><strong>Это полная гарантия отсутствия утечек?</strong></summary>

Нет. Защита работает на уровне процессов и реагирует с задержкой. Уже отправленные данные не отзываются. Если нужен запрет любых прямых соединений, включите сетевой kill switch VPN или настройте блокировку на роутере.

</details>

<details>
<summary><strong>Почему Claude перестал отвечать?</strong></summary>

Если в Russian Armor отображается пауза, процесс Claude приостановлен до свежего подтверждения разрешённой страны. Проверьте VPN и статус проверки. После успешной проверки работа возобновится. При статусе «Ошибка защиты» откройте пояснение: приложение не смогло выполнить необходимое действие и не заявляет об успешной защите.

</details>

<details>
<summary><strong>Что происходит после сбоя Russian Armor?</strong></summary>

Отдельный наблюдатель пытается приостановить распознанные процессы Claude и перезапустить приложение. Идентичности собственных пауз сохраняются для восстановления. Если наблюдатель недоступен, интерфейс предупреждает об этом, а допуск к работе отзывается. Это не заменяет постоянно действующие сетевые правила VPN.

</details>

<details>
<summary><strong>Что будет, если закрыть Russian Armor?</strong></summary>

Появится предупреждение об отключении защиты и закрытии Claude. После подтверждения приложение сначала закрывает распознанные процессы Claude; если они не завершаются, возможно принудительное закрытие. Если закрыть их не удалось, выход отменяется. Для продолжения защиты оставляйте Russian Armor работающим.

</details>

<details>
<summary><strong>Как обновить или удалить приложение?</strong></summary>

Автоматического обновления пока нет. Для обновления скачайте [последний DMG](https://github.com/danielsuchx/russian-armor/releases/latest/download/Russian-Armor.dmg), выйдите из старой версии через меню Russian Armor, затем перенесите новую **Russian Armor.app** в **«Программы»** и подтвердите замену. Извлеките образ и запустите приложение из **«Программ»**.

Для удаления сначала выйдите из Russian Armor, подтвердив отключение защиты и закрытие Claude. Затем переместите приложение из **«Программ»** в Корзину. Если вы собирали приложение самостоятельно, удалите созданную `.app`; исходный код также можно удалить. Локальные настройки и история при этом автоматически не стираются.

</details>

## Для разработчиков

<details>
<summary><strong>Клонирование, сборка и тесты</strong></summary>

```bash
git clone https://github.com/danielsuchx/russian-armor.git
cd russian-armor
bash scripts/build-app.sh release
```

Эта команда создаёт `.app` для архитектуры текущего Mac. Для универсальной сборки Apple Silicon + Intel:

```bash
bash scripts/build-app.sh release universal
```

Для готового установочного образа с универсальным приложением:

```bash
bash scripts/build-installer.sh
```

В `dist` появятся **Russian-Armor.dmg** и **SHA256SUMS.txt** с контрольной суммой образа. Готовые файлы для скачивания публикуются в [GitHub Releases](https://github.com/danielsuchx/russian-armor/releases/latest).

Для передачи другим людям используйте `release` — это режим по умолчанию у
`scripts/build-app.sh`. Он удаляет отладочную метаинформацию и проверяет отсутствие
локальных путей в исполняемом файле. Приложение собирается в новой временной папке:
в него копируются только исполняемый файл, `Info.plist` и иконка, затем добавляется
подпись. Содержимое прежней `.app`, настройки и история пользователя не копируются.
Явный режим `debug` сохраняет отладочную информацию и предназначен для разработки.

Запустить тесты:

```bash
swift test
```

Тест защиты использует только собственный дочерний процесс-заглушку. Пользовательские приложения не приостанавливаются. Ответы сервисов проверки в тестах подменены.

Отдельный тест отображения системного меню требует графической сессии macOS:

```bash
RUSSIAN_ARMOR_RENDER_MENU_TESTS=1 swift test --filter NativeMenuRenderingTests
```

Структура проекта:

```text
Sources/ArmorCore/        Модели, настройки и проверка ответов сервисов
Sources/ArmorTunnel/      Владелец туннеля и проверки через выбранный интерфейс
Sources/RussianArmor/    Защита процессов, наблюдатели, меню и окна
Sources/ArmorFirewall/   Экспериментальный системный helper
Tests/                   Тесты
Support/Info.plist        Сведения о приложении
scripts/build-app.sh      Скрипт сборки
scripts/build-installer.sh Универсальное приложение и установочный DMG
docs/protection.md        Контракт и границы защиты
```

</details>
