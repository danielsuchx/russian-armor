# Сетевой модуль Russian Armor 0.3

## Основа и интерфейс

Перенесено Rust-ядро [ai-antiban / «Застава»](https://github.com/kingbest1195/ai-antiban)
v2.3.0, коммит `cda7a4c14ca926a1e6951af62082a4cb89a18ae2`, по MIT.
Авторство и лицензия сохранены в `NetworkEngine/LICENSE`, `NetworkEngine/UPSTREAM.json`
и `THIRD_PARTY_NOTICES.md`. Окна и меню — SwiftUI/AppKit; React-интерфейс не включён.
Ядро работает как скрытый helper внутри `.app`, без окон WebView и отдельного трея.
В macOS для helper явно задан режим `Accessory` до запуска цикла событий:
он не появляется в Dock и переключателе приложений. Одного `LSUIElement`
недостаточно, поскольку стандартный режим Tauri — `Regular`.

функция macOS. JetBrains остаётся с неподтверждённой автоматической настройкой.

## Использование и прежняя защита

1. Открыть «Настройки → Сетевой шлюз» и нажать «Включить модуль».
2. При необходимости просмотреть изменения в «Дополнительные настройки → Изменения системы и диагностика».
3. Отдельно включить системный прокси и/или настройку CLI.
4. Назначить и проверить выходы в «Маршрутах», затем проверить покрытие в «Приложениях».

Первый запуск не меняет сетевые настройки автоматически. Выбор включённых
контуров сохраняется и восстанавливается после готовности восстановления и guard.
Прежние процессная защита и правила допуска сохраняются: разрешение шлюза
не снимает их запретов. Если настроенный модуль недоступен или его heartbeat
устарел, Claude остаётся на паузе и запуск под защитой недоступен.

При выходе сначала закрывается Claude, затем helper восстанавливает собственные
изменения. Ошибка восстановления отменяет обычный выход. Шлюз контролирует только
проходящие через него соединения, а не весь Mac. PAC и настройки отдельных
приложений могут не охватывать все способы подключения. HTTPS не расшифровывается.
Аудит и canary-тест не гарантируют отсутствие утечек или ограничений аккаунта.

## Данные и интеграция

- Состояние ядра: `~/Library/Application Support/app.russian-armor.network/`.
- `state.json` содержит настройки маршрутов, ключи/пароли прокси и историю
  выходных IP. Это локальное хранение с правами `0600`, без шифрования Keychain.
  Оно отличается от прежнего процессного контура, где наблюдаемые IP не сохраняются.
- Журнал: `ownership/journal.json` внутри этого каталога.
- Профили: `~/.russian-armor-network/claude_profiles/`.
- Маркеры оболочки принадлежат Russian Armor. Очистка чужих настроек по сигнатурам
  старой «Заставы» отключена, в том числе для CLI `--cleanup`.
- IPC: Unix-сокет `0600` в каталоге `0700`; проверяются UID и 256-битный токен
  из файла `0600`. Нет публичного HTTP-управления, eval или выполнения произвольных
  shell-команд. Размеры сообщений и число клиентов ограничены.
- До завершения восстановления изменение конфигурации через IPC запрещено.
- Сырые ответы остаются в памяти. Экспорт использует отдельную очищенную схему.
- Автозапуск, буфер обмена и обновления принадлежат основному приложению;
  helper не устанавливает себя или исходную «Заставу».

Источники проб перечислены также в `NetworkEngine/PRIVACY.md`: IP/GeoIP,
DNS/DNSBL, STUN и контрольные узлы видят адрес соответствующего запроса.
BIN передаётся только по кнопке; поле не принимает полный номер карты.
Автоматическая проверка GitHub Releases отключается в основных настройках.

## Сборка и проверка

Нужны Xcode/Swift и Rust stable (официальный rustup). Node.js не нужен.
Сборщик также находит локальную Rust toolchain в `.build/toolchains`.

```bash
swift test
cargo test --manifest-path NetworkEngine/src-tauri/Cargo.toml
bash scripts/build-installer.sh
```

`build-engine.sh` собирает arm64/x86_64 и включает лицензии зависимостей.
`build-app.sh` включает helper, уведомления MIT и публичный ключ в основной bundle.
Подпись выпуска — Ed25519 по версии, размеру и SHA-256; это нативный формат
Russian Armor, не minisign. Обновления и откат принимаются только из
`danielsuchx/russian-armor`; старые пакеты без подписи не предлагаются для отката.

Публичный ключ: `Support/UpdatePublicKey.txt`. Созданный локально закрытый ключ:
**`.release-signing/private.pem`**, права `0600`, исключён из Git и не входит
в приложение. Его нужно сохранить в приватной резервной копии. В CI файл ключа
передаётся через `ARMOR_SIGNING_KEY_FILE`; содержимое не выводится. Без ключа
можно собрать DMG для ручной установки, но автоматическое обновление требует
`Russian-Armor.dmg.sig`. Локальная ad-hoc подпись не является Apple notarization.
Автоматической публикации выпуска в этой задаче нет.

Проверки без изменения пользовательской сети:

```bash
RUSSIAN_ARMOR_RENDER_SETTINGS_TESTS=1 swift test --filter SettingsRenderingTests
cargo build --manifest-path NetworkEngine/src-tauri/Cargo.toml --bin zastava
python3 scripts/test-engine-ipc.py
ARMOR_ENGINE_IPC_TEST_BINARY="$PWD/NetworkEngine/src-tauri/target/debug/zastava" swift test --filter NetworkEngineTests
```

Debug-only smoke-режим использует пустое состояние и не запускает сетевой аудит,
восстановление или настройку прокси. Живые испытания сна Mac, смены Wi-Fi,
реального обрыва VPN и совместимости установленных клиентов требуют отдельной
проверки на тестовой системе; автоматические тесты их не заменяют.
