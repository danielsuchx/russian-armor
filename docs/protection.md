# Защита Claude на уровне процессов

Russian Armour работает без Network Extension и без прав администратора. При запуске
приложение сначала ставит распознанные процессы Claude на паузу, затем проверяет внешний
IP и страну. Работа продолжается только после свежего результата, совпадающего с выбранной
пользователем страной VPN.

## Первый запуск

1. Приложение немедленно переходит в закрытое состояние и приостанавливает найденные
   процессы Claude.
2. После появления сети внешний IP независимо проверяется через ipwho.is и IPinfo. Оба должны увидеть один адрес; страну для правила определяет ipwho.is.
3. Пользователь один раз нажимает «Разрешить страну XX» при включённом VPN.
4. Код страны сохраняется локально. При следующих запусках Claude автоматически остаётся
   на паузе до совпавшей проверки и затем продолжает работу.

IP не сохраняется. Разрешённый двухбуквенный код страны хранится в настройках приложения.

## Что приостанавливается

- корневой процесс Claude Desktop с bundle identifier `com.anthropic.claudefordesktop`;
- native Claude Code, если имя его исполняемого файла — `claude` или `claude-code`;
- npm-версия Claude Code в JavaScript-интерпретаторе по маркеру `@anthropic-ai/claude-code`;
- дочерние процессы этих программ, найденные по дереву родительских PID.

Перечисляются только процессы текущего обычного пользователя. Перед каждым `SIGSTOP` и
`SIGCONT` проверяются UID, PID и время запуска процесса, чтобы не отправить сигнал процессу,
получившему переиспользованный PID. Приложение продолжает только те процессы, которые
приостановило само.

## Когда Claude ставится на паузу

- при запуске Russian Armour;
- до первой настройки разрешённой страны;
- при системном изменении маршрута, сетевого адреса, интерфейса или наблюдаемого туннеля;
- перед сном и после пробуждения до свежей проверки;
- при ошибке, устаревании или отмене проверки IP;
- при несовпадении текущей и разрешённой страны.

Новые процессы подхватываются каждые 250 мс. Внешний выход фоново перепроверяется раз в
минуту, а также после системных событий сети. Плановая проверка не останавливает Claude до получения
отрицательного результата; смена сети или туннеля по-прежнему закрывает доступ немедленно.

## Границы защиты

Это защита на уровне процессов, а не сетевой фильтр. Между фактической сменой маршрута и
получением события macOS или следующим сканированием остаётся небольшой промежуток, в
котором возможен сетевой пакет. Для строгой гарантии «ни одного пакета мимо VPN» нужен
kill switch самого VPN или блокировка на роутере.

При обычном выходе из Russian Armour процессы, которые оно остановило, продолжаются, чтобы
не оставлять приложения зависшими. При аварийном завершении watchdog ставит найденные процессы Claude на паузу и
перезапускает основное приложение.

Старый экспериментальный Network Extension и Xkeen-адаптер остаются в исходниках для
исследований, но пользовательский сценарий их не устанавливает и не требует Apple Developer
Program.

## Проверки

`ProcessProtectionControllerTests` проверяет выбор Claude и всего дерева потомков, закрытое
состояние при запуске, несовпадение страны, продолжение после совпадения и защиту от
переиспользования PID. Полный пакет на 16 ноября 2026 года: 150 тестов, 1 графический тест
пропущен, ошибок нет.
